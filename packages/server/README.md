# 자체 호스팅 피드백 서버

Oracle ARM 또는 다른 Node 24 환경에서 실행하는 선택 서버임. SQLite 파일 하나에 댓글·사진·알림·수신 기록을 보존함. 단일 프로세스·복제본 1개로 사용함. 메모리 SDK를 사용하면 이 서버는 필요하지 않음.

[Oracle 배포 안내](../../deploy/oracle/README.md), [연결 계약](../../docs/oracle-server.md), [HTTP 어댑터](../http/README.md)를 참조함.

서버는 호스트 인증의 JWT를 공개 JWKS로 확인함. issuer·audience·sub·iat·exp가 필요하며 RS256/ES256과 최대 1시간의 토큰 나이를 허용함. 운영자가 별도로 등록한 프로젝트 멤버만 접근할 수 있음. 관리자 API·별도 계정 로그인·관리사이트는 제공하지 않음.

## 설정

`AUTH_ISSUER`, `AUTH_AUDIENCE`, `AUTH_JWKS_URL`, `PHOTO_TICKET_KEY`(무작위 32바이트 이상을 base64로 인코딩), `PUBLIC_BASE_URL`, `ALLOWED_ORIGINS`를 설정함. JWKS 주소와 외부 기본 주소는 HTTPS임. ALLOWED_ORIGINS는 쉼표로 구분한 정확한 웹 origin 목록이며 와일드카드를 허용하지 않음. 네이티브 요청도 bearer 검증을 거침.

`DATA_DIR` 기본값은 ./data, `HOST`는 127.0.0.1, `PORT`는 8080임. Docker 이미지는 내부 0.0.0.0:8080에서 실행함.

## 제한과 운영

사진당 5MiB·프로젝트 사진 합계 256MiB·프로젝트 댓글 스냅샷 8MiB를 제한함. 사진 삭제는 마지막 댓글 참조가 삭제될 때 함께 반영함. 등록하지 않은 사진은 24시간 이후 주기적으로 정리함. 버전 충돌·저장 제한을 통과하지 못한 쓰기는 원자적으로 취소함. 이벤트는 저장 성공 후에만 전달함.

매 HTTP 요청·사진 다운로드에서 현재 권한을 확인하고, WebSocket은 5초마다 권한과 JWT 만료를 확인함. 이미 내려받은 데이터의 회수는 보장할 수 없으므로 호스트는 로그아웃 시 SDK를 해제해야 함.

HTTP와 WebSocket의 실효 만료는 exp와 iat+1시간 중 이른 시각임. 계정 ID는 앞뒤 공백 없이 JWT sub 원문과 정확히 일치시킴. 정상 요청은 계정·프로젝트별 분당 180회이며, 서버 전체 보호 한도는 별도로 분당 6,000회임. 외부 Forwarded 헤더를 신뢰하지 않음.

운영자 명령은 서버의 신뢰된 터미널에서만 실행함. 데이터 디렉터리에 접근할 수 있는 사용자는 관리자이므로 해당 디렉터리를 공개하거나 웹 볼륨으로 제공하지 않음. 파일 복사 백업 대신 `backup` 명령의 SQLite 일관성 백업을 사용함.
