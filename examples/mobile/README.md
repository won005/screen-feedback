# Expo 예제

전시 준비 목록에 화면 댓글을 다는 Android/iOS 예제. 두 계정과 두 목록, 스크롤, 네이티브 상세 모달을 제공함. 댓글과 알림은 실행 중 기기 메모리에 저장됨. 사진은 기기의 선택기가 돌려준 임시 URI를 사용함.

## 실행

저장소 루트에서 실행함.

```sh
npm install
npm run build
npm run dev:mobile
```

Android 에뮬레이터 또는 Expo SDK 54를 지원하는 Expo Go에서 엶. iOS 시뮬레이터 실행에는 macOS가 필요함.

## 확인할 동작

1. 바를 **ON**으로 켬. 목록을 스크롤하고 체크박스를 짧게 눌러 기존 동작을 확인함.
2. 항목을 길게 눌러 댓글을 달고 목록을 스크롤해 핀이 항목과 함께 이동하는지 확인함.
3. 상세 화면을 열어 상세 영역 안에서 별도의 핀을 작성함. 바와 댓글창을 끌고, 바를 접었다가 펼침.
4. 사진만 첨부해 등록한 뒤 썸네일을 열어 크게 봄. 닫기 버튼, 바깥 터치와 Android 뒤로 가기를 확인함.
5. 미나 계정의 **다음** 목록에 **@준**을 포함한 댓글을 남김. **오늘** 목록에서 준 계정으로 전환하고 알림을 열면 **다음** 목록의 댓글로 이동함.
